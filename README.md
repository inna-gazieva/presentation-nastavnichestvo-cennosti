## О чём доклад

Наставничество рассматривается как социокультурный механизм трансляции традиционных духовно-нравственных ценностей ([Указ Президента РФ № 809](http://publication.pravo.gov.ru/document/0001202211090019)) в системе образования. На данных двух авторских исследований — «Ценности наставничества» (2025; проект Минобрнауки РФ «Школа наставничества», 150 участников, 33 региона, 42 эксперта) и опроса студенческой молодёжи (N = 3864, семь вузов, 2024) — показано: наставничество отличается от обучения добровольностью и взаимностью, а его главная функция — переводить ценности из «декларативных» (разрыв идеал–действие) в поведенчески устойчивые. Предложена пятиэтапная технология трансляции ценностей: **Контакт → Цели → Практика → Отделение → Преемственность**.
